# 🔘 ButtonMaker

> **100% Gratis & Open-Source Pin-Back Button & Badge Maker**  
> Een snel, modern en gratis alternatief voor commerciële tools zoals buttonmaker.app en cutoutdesigner.app. Zonder abonnementen, zonder limieten en zonder verplichte accounts.

🌐 **Live Demo:** [https://fabjan4u.github.io/buttonmaker/](https://fabjan4u.github.io/buttonmaker/)

---

## ✨ Waarom ButtonMaker?

Commerciële websites zoals `buttonmaker.app` laten je maximaal 5 ontwerpen per maand downloaden en vragen daarna \$9 tot \$24 per maand. Deze open-source tool draait **100% in je browser**:

- 🆓 **100% Gratis voor altijd:** Geen downloadlimieten, geen watermerken, geen paywalls.
- 🔒 **Volledige privacy:** Jouw foto's en ontwerpen worden lokaal in je browser verwerkt en verlaten nooit je apparaat.
- 🖨️ **Exact op ware grootte (300 DPI PDF):** Download printklare PDF's op A4 of US Letter formaat die exact passen in je buttonpers of stans.
- ⚡ **Supersnel:** Geen laadtijden van servers, werkt direct op desktop, tablet en mobiel.

## 🎯 Belangrijkste Functies

### 1. Nauwkeurige Formaten & Sjablonen
Ondersteunt alle gangbare buttonpersen (Tecre, Badge-It, Enterprise Products, Chinese 58mm persen, etc.):
- **25 mm (1")** – Klassieke band & punk buttons (Snijmaat: 35.2 mm)
- **32 mm (1.25")** – Ideaal voor portretten en logo's (Snijmaat: 44.0 mm)
- **37 mm (1.5")** – Badge-It Classic formaat (Snijmaat: 48.8 mm)
- **44 mm (1.75")** – Campagne badges (Snijmaat: 54.0 mm)
- **50 mm (2")** – Fotobadges, zakspiegels en flesopeners (Snijmaat: 63.0 mm)
- **58 mm (2.25")** – *De populairste Europese hobbymaat* (Snijmaat: 70.0 mm)
- **75 mm (3")** – Grote statement buttons (Snijmaat: 86.3 mm)
- **Tecre US 1.25" & 2.25"** – Amerikaanse ponsmaten
- **Aangepaste maat (Custom):** Voer zelf je eigen afmetingen in millimeters in.

### 2. Drie Visuele Gidszones
- 🟢 **Zichtbaar vlak (Face):** Het gedeelte dat straks te zien is op de voorkant van de button.
- ⬛ **Bleed vlak (Omslag):** De rand die om de metalen schelp heen vouwt.
- 🔴 **Snijlijn (Cut line):** De exacte buitenmaat waar je knipt of stanst.

### 3. Krachtige Editor
- **Afbeeldingen:** Sleep afbeeldingen naar het canvas, zoom met het muiswiel, verplaats direct met de muis, roteer, spiegel horizontaal/verticaal en pas helderheid/contrast/zwart-wit aan.
- **Tekst & Boogtekst (Curved Text):** Plaats rechte tekst of gebogen tekst langs de boven- of onderboog van de button. Kies uit Google Fonts, pas tekstkleur en omtreklijnen (stroke) aan.
- **Achtergronden:** Kies effen kleuren, kleurverlopen (lineair of radiaal), of een transparante achtergrond.
- **3D Badge Mockup:** Zie direct hoe de fysieke button eruitziet met een realistische bolling en glanslaag.

### 4. Automatisch Vel Vullen & PDF Export
- **A4 & US Letter ondersteuning:** Berekent automatisch hoeveel buttons er op één vel passen.
- **Snijlijnen & Middenkruis:** Print met dunne stippellijnen en een middenkruisje voor cirkelsnijders.
- **50 mm Kalibratiebalk:** Een meetlatje op het vel zodat je met een liniaal direct kunt verifiëren of je printer op 100% schaal staat.
- **Hoge Resolutie PNG:** Exporteer losse buttons in 1200×1200 px.

## 🚀 Lokaal Ontwikkelen

```bash
# Clone het project
git clone https://github.com/fabjan4u/buttonmaker.git
cd buttonmaker

# Installeer afhankelijkheden
npm install

# Start development server
npm run dev

# Bouw productiebundel
npm run build
```

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS
- **Iconen:** Lucide React
- **PDF Generatie:** jsPDF (vector + raster 300 DPI)
- **Hosting:** GitHub Pages via GitHub Actions
